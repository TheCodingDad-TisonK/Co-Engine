## 📖 About

Co-Engine is a custom game engine created by [TheCodingDad-TisonK](https://github.com/TheCodingDad-TisonK) to build a series of unique, code-only games. Rather than using off-the-shelf engines, Co-Engine was built specifically to support the ideas and gameplay systems of the Co-Series from the ground up.

---

## 🎮 Projects Powered By Co-Engine

| Project | Description |
| :-- | :-- |
| [**Park Co**](https://github.com/TheCodingDad-TisonK/Park-Co) | Theme park simulator with rides, railway, and park management |
| [**Depot Co**](https://github.com/TheCodingDad-TisonK/Depot-Co) | First-person warehouse & logistics simulator |
| [**Grow Co**](https://github.com/TheCodingDad-TisonK/Grow-Co) | First-person shop simulator with growing, curing, packing & selling |
| [**Garage Co**](https://github.com/TheCodingDad-TisonK/Garage-Co) | First-person car workshop simulator |

## ✨ Features

- **🧩 Modular Design** - Built to be shared across multiple games in the Co-Series
- **⚡ Lightweight & Custom** - Tailored specifically for the unique needs of each project
- **🛠️ Built-In Tooling** - Includes tools for building, serving, branding, and more
- **🎨 Code-Only Rendering** - Many assets are procedurally generated in code
- **🔌 Extensible** - Designed to grow alongside the games it powers
